# Frontend

Next.js App Router frontend using React, TypeScript, and Tailwind CSS. Routes live in `src/app/`; shared UI lives in `src/components/`; server-side backend client code lives in `src/lib/`.

Run from the repository root with `npm run dev:frontend`, or use `npm run dev` to start both services. Copy `.env.example` to `.env.local` and set `BACKEND_API_URL`. Do not add Supabase service-role keys or provider secrets to the frontend environment.
